# VYBE Launcher Icon Design Specifications

## Design Theme
- **Background**: Dark navy (#1A237E) with violet-to-cyan gradient
- **Foreground**: Bold white "V" symbol
- **Monochrome**: White "V" symbol for monochrome icons
- **Round Variants**: Blue-to-pink-to-green gradient background

## Adaptive Icon Structure (Android 13+)
- **Background**: `icon_background_vybe.xml` (gradient)
- **Foreground**: `icon_foreground_vybe.xml` (vector V symbol)
- **Monochrome**: `icon_plane_vybe.xml` (simple V symbol)

## Density-Specific Assets
- **hdpi**: 48x48 dp
- **mdpi**: 36x36 dp
- **xhdpi**: 72x72 dp
- **xxhdpi**: 96x96 dp
- **xxxhdpi**: 144x144 dp

## Preview Instructions
1. Open the project in Android Studio
2. Clean and rebuild the project
3. Install the app on an Android device or emulator
4. The app should display the VYBE launcher icon
5. Check both regular and round icons
6. Verify the icon appears correctly on different screen densities
